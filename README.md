## Overview

Caption Generator Pro brings AI-assisted subtitle and caption creation into Adobe video workflows. Through OpenAI Whisper transcription, the extension converts spoken dialogue into editable text that can be used in Adobe Premiere Pro and After Effects.

It is built for editors, motion designers, and video teams handling footage with substantial dialogue. Instead of switching away from the tools used for editing and compositing, users can prepare text-based video elements within the Adobe environment they already work in.
